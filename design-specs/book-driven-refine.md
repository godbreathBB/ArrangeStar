# ArrangeStar 设计修饰依据：两本设计经典的落地笔记

> 本篇记录「学习两本书 → 对照 APP → 克制落地」的完整链路，作为本次修饰的设计依据。
> 来源书目：
> 1. 《视觉传达设计》 Robin Landa（人民邮电出版社，2018）——设计原则、格式塔、版式、对比、节奏。
> 2. 《平面设计200年》 Steven Heller & Seymour Chwast（第四版）——包豪斯、瑞士国际风格、新简约主义、信息可视化。

## 一、从书中提炼的原则（只取对「小屏命理排盘界面」有效者）

### 《视觉传达设计》罗宾·兰达

| 原则 | 书中要点（原文要义） | 对本 APP 的含义 |
|---|---|---|
| 平衡 Balance | 关乎稳定性；色块/暗色有更大视觉重量 | 深色底 + 金色强调需保持重心稳定，避免一侧过满 |
| 层级 Hierarchy | 「通过组织视觉层次来突出重点，可以改进传达效果」 |  today 金句 / 宫位主星 / 辅助标注要有明确主次 |
| 统一 Unity | 格式塔：相似、邻近、连续、闭合、同向；大脑寻求整体与秩序 | 同性质元素（小标签、徽章、宫格）应共享一致的形状/间距/颜色语言 |
| 节奏 Rhythm | 「重复建立视觉节奏，任何变化都将打破节奏」；变化太多会削弱节奏 | 宫格、卡片、列表间距要成体系，避免随意数值 |
| 对比 Contrast | 「明度对比度最能区分图形与背景」；高对比易引起注意 | 关键信息（金句、主星、当前态）靠明度/色彩对比跳出，而非加大字号 |
| 版式 Format | 手机屏幕是一种特定版式；设计要在既定边界内展开 | 窄屏下信息密度高，克制装饰、保证可读 |

### 《平面设计200年》海勒 / 切瓦斯特

| 流派 | 书中要点（原文要义） | 对本 APP 的含义 |
|---|---|---|
| 包豪斯 | 「由功能性需求决定，而非对风格的痴迷」；本质特征是秩序感、不对称、矩形网格结构 | 界面服务排盘功能，网格是骨架；不堆砌无功能装饰 |
| 瑞士国际风格 | 「排列以客观实用为标准；构图区域按数学比例精心设计，同时关注字体排版规则」 | 间距/字号成比例系统，对齐严格 |
| 新简约主义 | 「简化文字与图片的层次，只保留最基本的形式与信息；帮助受众更高效地阅读」 | 解读区减少视觉噪音，正文行距/留白利于扫读 |
| 信息可视化 | 「用可视方法传达数据，比纯文本更能吸引注意」 | 五行能量条、九宫格本身就是信息可视化，应保证其清晰 |
| 少即是多 | 密斯·范德罗信条，新现代主义的避难所 | 金色只用在重点，避免处处高亮导致重点失效 |

## 二、对照 APP 现状的诊断（不推翻用户已定决策）

保留：深空金主题、4 页奇门引导、收紧的出生输入格、中英双语、九宫格功能结构。

| 差距 | 对应原则 | 是否处理 |
|---|---|---|
| `.wrap` 与卡片缺少统一间距节奏，正文在宽屏上行长过长 | 节奏 / 版式 / 新简约 | ✅ 建立间距节奏令牌 + 正文最大行宽 |
| 解读正文（`.dsec p` 等）无 measure 限制，超宽屏阅读吃力 | 版式 / 新简约（高效阅读） | ✅ 正文加 `max-width`，窄屏不受影响 |
| 金句 `.db-main` 与标签同级感弱，重点不够跳 | 层级 / 对比 / 少即是多 | ✅ 强化金句字距与行高，标签用字距弱化 |
| 页签/ Capitol 按钮 focus 样式此前缺失 | 统一 / 可达性 | ✅ focus-visible（已在先前版本落地，本次保持） |
| 明度对比：辅助字 11px 偏小 | 对比 | ⚠️ 部分保留——九宫格密集标注若放大到 14px 会撑破网格，权衡后维持 |
| 输入框 30px < 44px 点击区 | 节奏 / 版式 | ⚠️ 用户已明确要求收紧输入格，尊重决策，不放大；改用隐形命中区（先前版本已落地） |

## 三、本次落地的修饰（克制，改 CSS 不改逻辑）

1. **间距节奏令牌**：在 `:root` 定义 `--sp-1..--sp-5`（4/8/12/16/20px），解读区 `.dsec` / 段落 / 页脚改用令牌，统一视觉节奏（节奏 + 瑞士比例）。
2. **正文行宽上限（measure）**：`.dsec p` / 解读段落设 `max-width:62ch` 左右，宽屏不拉长、窄屏无影响（版式 + 新简约）。
3. **金句层级强化**：`今日一句 .db-main` 略微放大、加字距与行高，强化视觉重量；其元信息行保持小字弱对比（层级 + 对比 + 少即是多）。
4. **统一圆角语言**：新增 `--radius` 令牌并让解读卡片 `.dsec` 采用（6px），避免与其它面板的圆角值无规律漂移（统一 + 格式塔相似）。其余面板因涉及既有布局保持稳定，不强行改动。
5. **`prefers-reduced-motion`**：保持已有适配（可达性）。
