# 星垣 · 四象星图视觉方案（四兽线稿 + 水体纵深 + 二十八宿）

> 分支：`design/four-symbols-sky`。本文件是本次改动的**设计依据**，说明三张参考图的视觉语言如何转译为界面资产。
> 上游单一事实来源：`design-specs/visual-system.md`（传统色令牌）；本文件在其之上补充"图像层"规范。

## 1. 参考图语言提取

### 图 1 · 线稿（白描技法）

参考是一幅精细黑白线稿。可复用的技法不是"画一个少女"，而是**白描的用笔逻辑**：

| 技法 | 特征 | 转译到四兽 |
|---|---|---|
| 长曲线勾形 | 流畅、有弹性的轮廓线，粗细有变化 | 龙身蜿蜒、虎躯张弛、雀翼舒展、龟蛇缠绕均用单线勾勒，不填色 |
| 密集排线表体积 | 花瓣/翅膀用平行短线排布出明暗 | 龙鳞、虎纹、雀羽、龟甲纹用规律短线/网格排布 |
| 散点装饰 | 大小不一的墨点环绕主体 | 星点、云气点、朱砂点散落四周 |
| 疏密与留白 | 主体密、四周疏，大量留白 | 四兽只作低透明度水印，中心内容区保持空净 |

**关键约束**：线稿是"背景水印"，不是"插画主角"——必须低对比度、可被文字压过。

### 图 2 · 明暗关系（水体纵深）

参考是《海中遨游》水下油画。转译的是**明暗结构**，不是具体物体：

- **上段（受光）**：水面透光的淡青紫／雾蓝，明度高、色温偏冷偏亮 —— 对应引导页顶部
- **中段（光束）**：一束斜射的冷光柱穿透，主体在光束中显出青绿灰的明暗交界 —— 对应引导页主视觉区
- **下段（沉入）**：深靛蓝／群青，明度低 —— 对应引导页底部
- **高光点**：银灰／淡金的悬浮微光点，提亮暗部 —— 对应引导页星点
- **空间纵深**：近深远浅、雾状柔化 —— 用多层半透明渐变叠加实现

**关键约束**：光从上方来，标题与符号必须落在受光区；暗部只放次要元素。

### 图 3 · 中国古代星术（二十八宿）

参考是二十八宿天球图。可转化的符号：

- **二十八宿星点连线**：四象各七宿，点与点用细线相连 —— 引导页背景星官
- **四象方位**：东青龙、西白虎、南朱雀、北玄武 —— 版面四兽的方位依据
- **椭圆天球轨道**：中心天体 + 椭圆轨道 —— 引导页主视觉的"天球"骨架
- **四时标记**：春／夏／秋／冬与节气 —— 星图上的古风文字点缀
- **配色**：靛蓝底 + 淡金/白星点 —— 与现有泥金体系天然契合

## 2. 转译规则（实现契约）

### 2.1 四兽线稿 → 版面背景（`css/style.css` 的 body）

- 四兽各绘为**独立白描线稿 SVG**（见 `assets/symbols/`），纯 path、无填充、泥金细线。
- 方位：青龙居左（东）、白虎居右（西）、朱雀居上（南）、玄武居下（北）——以水墨"四神护佑"构图铺开。
- 以 `background-image` 叠在现有三层星图之上，**整体透明度控制在 0.05–0.09**，仅在水印层可辨；正文/卡片之下不喧宾夺主。
- 保留现有 `background-attachment:fixed` 与星点层，四兽层加入其后。

### 2.2 水体纵深 → 引导背景（`css/onboarding.css` 的 `.ob-root`）

用多层 CSS 渐变模拟图 2 的明暗结构（自上而下）：

1. 顶部受光：淡青紫／雾蓝径向高光（`rgba(168,180,220,*)→rgba(90,110,170,*)`）
2. 斜射光束：一条 15–25° 倾斜的冷光柱，用 skew 的线性渐变，低透明度
3. 中段过渡：石青／黛蓝
4. 底部沉入：深靛蓝／玄青
5. 银灰高光点：若干带柔光的微光点（保留现有 ob-sky-star 并补密度）

标题、四象符号、按钮落在中上受光区，保证对比度。

### 2.3 二十八宿 → 星术元素（两处）

- **引导页**：新增 `.ob-mansions` 星图 SVG 背景层——四象七宿星点连线 + 中心天球轨道 + 四时字，围绕主视觉缓慢旋转（`prefers-reduced-motion` 下静止）。
- **主界面**：四兽线稿自带云气散点，与现有星点层呼应，不再额外叠加星官以免喧宾。

## 4. 可读性与无障碍契约（不可破坏）

- 四兽线稿透明度 ≤0.09，`pointer-events:none`，不参与聚焦。
- 引导文字对比度维持现有水准；星图/光束层 `pointer-events:none` 且置于文字层之下（z-index）。
- `prefers-reduced-motion` 下：星图旋转、光束浮动全部静止。
- 双语文案、DOM 结构、交互逻辑一律不改——本次只改视觉层。
