# 星垣 · 四象星图视觉方案（四神兽法相 + 白描 + 水体纵深 + 二十八宿）

> 分支：`design/four-symbols-sky`。本文件是本次改动的**设计依据**，说明四张参考图的视觉语言如何转译为界面资产。
> 上游单一事实来源：`design-specs/visual-system.md`（传统色令牌）；本文件在其之上补充「图像层」规范。
> 可复现生成器：`tools/gen_symbols.py`（纯标准库）；渲染预览：`swift tools/svg2png.swift` 或 Chrome 无头。

## 1. 四张参考图的分工与语言提取

四张图各司其职，**不可混用**：形制取图 1、笔法取图 2、明暗取图 3、符号取图 4。

### 图 1 · 四神兽拓片（形制法相）

参考是青龙／白虎／朱雀／玄武的黑白拓片式造型，为**图案化纹样神兽**而非写实动物：

| 兽 | 法相特征 | 转译要点 |
|---|---|---|
| 青龙 | 昂首右向、S 形躯干（颈细·胸宽·腹收·臀隆）、分叉角与后掠鬃、四足带三爪、长尾上卷成涡、背脊鳍 | 躯干用起伏贝塞尔，不用平直长条 |
| 白虎 | 朝左行走、虎首张口露齿、额纹、**卷云／火焰状虎纹**、尾高卷成 S 涡 | 虎纹是连续涡卷，不是竖条纹 |
| 朱雀 | 三支卷曲凤冠、**双翼向上后方展开的层叠羽片**、尾羽为向右飘展的长卷草蔓纹、双足立 | 双翼须有面积，尾羽不可下垂如触手 |
| 玄武 | 龟蛇缠绕、**六边形龟甲纹**、蛇首回首贴龟背、四足短尾 | 蛇首宜小，过大则似鸟头 |

共同语言：**S 形卷云涡卷**贯穿首尾冠羽；躯干为**实黑块 + 白色线纹**的拓片阴阳关系；大量留白与极密纹样强对比。

### 图 2 · 唯美白描（笔法）

可复用的不是题材，而是**白描用笔逻辑**：

- 三级线宽：轮廓 2.0 / 结构 1.2 / 排线 0.6；卷云纹 1.7–2.3
- **密集平行排线成块**（`hatch`）：近看全是线，远看有块面 —— 正是把图 1 的"实黑块"转译为深底上"泥金密线块"的桥梁
- **月轮双圆构图** + 沿弧点状墨点（大小渐变）
- 花叶藤蔓环绕主体、卷云如意纹
- **极密与大片留白**强对比

### 图 3 · 《海中遨游》水下油画（明暗）

转译的是**明暗结构**，不是具体物体：

- 上段受光：水面透光的淡青紫／雾蓝，明度高、色温偏冷 —— 引导页顶部
- 中段光束：斜射冷光柱穿透，主体在光束中显明暗交界 —— 引导页主视觉区
- 下段沉入：深靛蓝／群青，明度低 —— 引导页底部
- 银灰／淡金悬浮微光点提亮暗部；多层半透明渐变做雾状纵深

**约束**：光从上方来，标题与符号必须落在受光区；暗部只放次要元素。

### 图 4 · 二十八宿天球图（星术）

- 四象各七宿的**星点连线**；四象方位（东青龙／西白虎／南朱雀／北玄武）
- **椭圆天球轨道** + 中心日月；**春夏秋冬**四时标记
- 靛蓝底 + 淡金星点，与既有泥金体系天然契合
- 中心天体 → 转译为「**众星拱北辰**」的北斗七星 + 北极帝星

## 2. 转译规则（实现契约）

### 2.1 四兽白描 → 版面背景

- 生成器 `tools/gen_symbols.py` 产出 4 张单稿 + 1 张合成水印 + 1 张二十八宿星图，全为可编辑 SVG。
- **拓片实块**：每兽定义 `<pattern id="hatch-{兽名}">` 密斜线（间距 3.4px、线宽 1.15px），兽身闭合 path 以 `fill="url(#hatch-*)"` 填充，再叠 `W_CONTOUR` 轮廓描边 —— 实块内全是线，不引入色块。
- **卷云纹带**：`curl_band()` 沿躯干排布大小渐变的内卷涡（亮泥金），还原图 1「实块内满布流动白线」；`spiral_tail()` 生成上卷涡尾；`claw()` 生成三爪。四肢用线勾，与实块形成疏密对比。
- **白描装饰**：`moon_ring()` 月轮双圆 + 点墨、`cloud()` 如意云、`vine()` 花叶藤蔓、`feather()` 羽枝。
- **星术入版面**：每兽携所属七宿（星点连线 + 一字一宿 + 竖排方位题名）：角亢氐房心尾箕／奎婁胃昴畢觜參／井鬼柳星張翼軫／斗牛女虛危室壁。
- **竖屏画布**：合成水印 `viewBox="0 0 720 1560"`（≈430×920 移动端竖屏比）。正方形画布在 `contain` 下只占中部一小块、会被半透明卡片盖没；竖屏画布才能铺满版面。四象方位为朱雀上／玄武下／青龙左／白虎右，中央留白。
- **北斗拱极**：`big_dipper()` 置于中央 —— 斗魁四星 + 斗柄三星 + 天枢→天璇延长 5 倍的北极帝星（四芒 + 三重光晕）+ 两道拱极天球弧。呼应图 4 中心天体与既有 PWA 图标「众星拱北辰」。
- `body::before` 固定层：`contain` 铺满不裁切、`z-index:-1` 位于渐变星空之上内容之下、`pointer-events:none`、24s 呼吸动画。

### 2.2 透明度 0.30（真实页面三档实测）

水印 alpha 由**真实主界面**对比确定，不是纯底目测：

| alpha | 纯深蓝底 | 真实主界面（半透明卡片压低水印） | 结论 |
|---|---|---|---|
| 0.18 | 隐约可辨 | 几乎不可见 | 等于没做 |
| 0.24 | 清楚 | 勉强透出 | 偏保守 |
| **0.30** | 略抢眼 | **四兽可辨、正文完全不受影响** | **采用** |

卡片有 `rgba(16,20,42,.55)` 底色，会削弱水印；水印层本身在内容之下，故 0.30 在真实页面上仍是克制的背景。

### 2.3 水体纵深 → 引导背景

`css/onboarding.css` 的 `.ob-root` 用多层 CSS 渐变：顶部冷青紫受光 → 18° 斜射冷白光束（`.ob-lightbeam`，screen 混合）→ 中段石青／黛蓝 → 底部玄青沉入 → 银灰微光星点。
`.ob-root` 加 `overflow:hidden` 裁掉 150vmin 星图层与光束层的溢出，防止撑出横向滚动区。

### 2.4 二十八宿 → 星术（三处）

1. **引导页**：`.ob-mansions` 星图 SVG —— 四象七宿星点连线 + 三层椭圆天球轨道 + 春夏秋冬 + 中心日月，90s 缓慢旋转。
2. **四兽单稿**：每兽所属七宿星官 + 竖排方位题名。
3. **合成水印中央**：北斗七星 + 北极帝星 + 拱极轨道。

`prefers-reduced-motion` 下全部动画静止。

## 4. 可读性与无障碍契约（不可破坏）

- 水印 `alpha=0.30`（生成器内）、`pointer-events:none`、`z-index:-1`、不参与聚焦；调节只需改 `four_creatures()` 默认参数重跑。
- 引导文字对比度维持现有水准；星图／光束层 `pointer-events:none` 且置于文字层之下。
- `prefers-reduced-motion`：星图旋转、光束浮动、水印呼吸全部静止。
- 双语文案、DOM 结构、交互逻辑一律不改 —— 本次只改视觉层。
- 引导页页脚按钮在精确 430px 视口下完整显示（`right=395.9 < 430`）；无头浏览器直开页面的"贴边"是 `--window-size` 最小视口导致的截图假象，非真实缺陷。
