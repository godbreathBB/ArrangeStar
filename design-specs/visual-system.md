# 星垣 ArrangeStar · 全盘视觉系统规范 v1.0

> 分支：`design/visual-system`。本文件是「引导动画 → 版面背景」全盘视觉设计的**单一事实来源**（single source of truth）。
> 所有色值、层次、纹样、动效参数以此为准，CSS 中的令牌须与本文一致。

---

## 一、设计立意

三个词：**深空 · 星垣 · 泥金**。

- **深空**：术数推演发生于夜空之下，背景是星图而非纯色。
- **星垣**：三垣二十八宿环列，"垣"即星之墙——界面容器取"垣墙"意象（细金线围合）。
- **泥金**：传统典籍以泥金抄录星图，强调色是泥金而非亮黄。

设计克制原则（延续 `book-driven-refine.md`）：
- 金色只用在**重点**，不做大面积铺陈；
- 装饰**不干扰可读**，正文对比度优先；
- 尊重用户已定决策：4 页引导、九宫功能结构、中英双语、深空金主题均不推翻。

## 三、背景系统（深空星图）

### 3.1 层次（由底至顶）

1. **底层**：径向渐变石青→黛蓝→玄青，光源在屏幕上方偏中（`at 50% 30%`），模拟夜穹中心微亮。
2. **星点层**：三层不同亮度的星点，用多重 `radial-gradient` 绘制，无图片依赖。
3. **叙事层**：引导页在星点层上叠"垣环"光晕，强化主题。

### 3.2 星点绘制参数（关键）

> 现状缺陷：原星点仅 1–1.6px、静态、低透明，真机几乎不可见 → "深空"只剩深蓝。

统一规格：
- **亮点**：`1.5px–2px`，透明度 `0.5–0.75`，米白/泥金。
- **暗点**：`1px`，透明度 `0.2–0.35`，形成密度。
- **微光晕**：最重要的 3–5 颗星加 `box-shadow / 渐变晕`，半径约 `8px`，透明度 `0.25`。
- **位置**：固定百分比坐标（不随机），保证每次渲染一致、可复现。
- **数量**：背景约 14–18 颗；引导遮罩约 9–11 颗（避免与插画抢视线）。
- **动画**：仅引导遮罩的星点做 `twinkle`（2.4–3s，错峰 delay）；主界面背景星点**静止**，避免阅读干扰。

### 3.3 容器（"垣墙"意象）

边框体系沿用现有实现中**已有的规律**，不推翻、不无谓改动：

- **泥金系**（`--line-gold` 家族，`.28–.5`）：强调容器与交互件——九格外框、今日一句条、按钮、选中态。金线较重，表示"可交互 / 重点"。
- **素笺系**（`--line-ink` 家族，`.12–.16`）：中性内容容器——宫格 `.palace`、解读卡 `.dsec`、奇门宫 `.qpal`、表格。白线较轻，退让给内容。
- 这套"金重白轻"的层级是**刻意的视觉秩序**，保留现状数值差异；新增容器按此规律选边：交互/强调用金，内容承载用素笺。
- 选中/聚焦：泥金描边加粗 + 极淡内发光 `box-shadow: 0 0 0 2px rgba(201,162,39,.3)`。
- 圆角统一：`--radius:6px`（面板）、`--radius-lg:10px`（大容器），延续现有令牌。

## 四、引导动画（4 页）

沿用现有 4 页主题（八卦 / 九宫 / 竹简 / 卷轴），统一视觉语言：

| 页 | 主题 | 主符号 | 泥金焦点 | 动效节奏 |
|---|---|---|---|---|
| 1 | 品牌 | 太极八卦环 | 太极 + 帝星 | 缓旋 26s + 星点 twinkle |
| 2 | 排盘 | 洛书九宫 | 中宫「五」 | 宫格 0.13s 逐格亮起 |
| 3 | 断辞 | 竹简 |  Muddy-gold 字 | 0.18s 逐简展开 + 逐字浮现 |
| 4 | 讲堂 | 卷轴书签 | 泥金轴头 | 0.85s 展开 + 书签浮现 |

统一处理：
- **遮罩**：由纯黑 `rgba(0,0,0,.85)` 改为深空渐变（与主体同源），使引导与主界面气质连贯。
- **配色令牌**：`:root` 全量对齐本文第二节。
- **标题**：泥金渐变 + 极淡发光，字距 `.14em`。
- **动效**：保持 `prefers-reduced-motion` 适配；所有动画只作用于插画层，不作用于正文。
